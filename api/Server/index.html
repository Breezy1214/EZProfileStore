Server

This item only works when running on the server. Server

Owns player sessions and replicates server mutations.

Mutate​

</>
Server:Mutate(
player: Player,
transform: (data: {[any]: any}) → ...boolean
) → boolean--

true if the draft was committed.

Edits a draft copy of the player's data and commits it all-or-nothing.

The transform must not yield. If it errors, returns false, produces unsavable values, or fails config.validate, live data is untouched. Otherwise the draft is diffed against live data and only the changed paths are written and replicated. 

store:Mutate(player, function(data)
	if data.Coins < 100 then
		return false
	end
	data.Coins -= 100
	table.insert(data.Inventory, "Sword")
end)

MutateMany​

</>
Server:MutateMany(
players: {Player},
transform: (drafts: {[Player]: {[any]: any}}) → ...boolean
) → boolean--

true if every draft was committed.

Like Mutate, but commits drafts for several loaded players together or not at all.

Use it for trades so a failed check cannot leave one side changed. ProfileStore still saves each profile independently, so this is atomic in memory, not across a server crash.

OnMessage​

</>
Server:OnMessage(handler: MessageHandler) → () → ()--

Disconnects the handler.

Handles messages for loaded profiles, including ones already waiting. Call processed after applying a message (usually with Mutate) so it is not delivered again. 

store:OnMessage(function(player, message, processed)
	if message.type == "Gift" and store:Mutate(player, function(data)
		data.Coins += message.coins
	end) then
		processed()
	end
end)
